AlgoLens — Algorithm Complexity Visualizer
Understand algorithms by seeing their complexity unfold.

What is AlgoLens?
Most students memorize algorithm complexity. AlgoLens helps you understand it.
Paste any algorithm and AlgoLens instantly shows you:

Why it's O(n), O(n log n), or O(n²)
How the recursion tree expands
How runtime grows as input size increases
The recurrence relation and its step-by-step expansion


Features

Complexity Detection — Automatically detects time & space complexity
Recursion Tree — Visual call tree with depth-colored nodes
Growth Chart — Plots all complexity curves, highlights yours
Recurrence Expansion — Step-by-step from T(n) = 2T(n/2) + n to O(n log n)
Plain English Explanation — Explains why the complexity arises
Preloaded Examples — Merge Sort, Bubble Sort, Binary Search, Fibonacci

Tech Stack - React, D3 SVG, Claude API (claude-sonnet-4), JetBrains Mono, Syne
